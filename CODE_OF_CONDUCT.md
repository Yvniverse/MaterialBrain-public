# Code of Conduct

MaterialBrain aims to keep technical collaboration professional, respectful, and useful.

Participants are expected to:

- discuss ideas and code without personal attacks;
- give specific, evidence-based technical feedback;
- respect privacy, confidentiality, licenses, and security boundaries;
- avoid harassment, discrimination, intimidation, or deliberately disruptive behavior;
- follow maintainer requests when a discussion needs to return to technical scope.

Serious conduct concerns should be reported privately to the repository maintainer rather than litigated in public issue threads. Maintainers may remove content or restrict participation when necessary to protect contributors and the project.

# Support

Use the repository's [issue forms](https://github.com/Yvniverse/MaterialBrain-public/issues/new/choose) for reproducible bugs, usage questions, documentation fixes, and feature requests.

Include the application version, operating system, relevant configuration names, and reproduction steps. For spatial or robot issues, include the map version, mission status, and transport type. Remove credentials, session cookies, customer records, and sensitive file contents from logs.

Start with the [documentation index](docs/README.md), [Spatial Agent guide](docs/SPATIAL_AGENT.md), or [robotics guide](docs/ROBOTICS.md). Report security vulnerabilities through the process in [SECURITY.md](SECURITY.md).

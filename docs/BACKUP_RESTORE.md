# 备份与恢复

自动备份容器启动后立即备份一次，并按 `BACKUP_SCHEDULE` 定时执行。数据库使用 PostgreSQL custom dump，附件和受管工程证据原文件分别使用 tar.gz，同一时间戳清单记录三者 SHA-256。保留策略只清理匹配命名且超过天数的文件。

恢复前把备份目录复制到另一物理设备并验证 `Get-FileHash`/`sha256sum` 与清单一致。在测试环境运行恢复脚本；脚本先做保护性备份，再停后端、用 `pg_restore --clean --if-exists` 恢复并解压同时间戳附件与受管工程证据原文件。完成后检查迁移版本、管理员登录、物料数量、最近流水、附件下载、真实数据手册打开/哈希校验和新备份。RAID、同步盘和数据库卷快照都不能单独替代离线/异机备份。

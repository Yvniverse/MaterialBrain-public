# 固定种子空间任务规划：CPU 结果

在固定的 1,000 项任务、单 CPU 线程与 V4 原有 2 秒求解上限下，规划器返回如下结果。这是任务规划基准，与语言模型后训练和 Nav2 行驶结果分别计量。

| 指标 | 结果 |
|---|---:|
| 独立审计可行计划 | 791/1,000 |
| 预先证明不可行请求的正确拒绝 | 192/192 |
| 未获得可行解且未证明不可行的搜索失败 | 17/1,000 |
| 约束违规／几何碰撞／程序错误 | 0／0／0 |
| V4 请求内规划 p50／p95 | 406.28／621.63 ms |
| 完整 CPU 执行耗时 | 1,452.035 s |

**另一项 V3 内部比较。** 对相同的 234 个可行配对任务，V3 优化相对输入顺序使总目标下降 26.39%、总距离下降 32.21%。这不是 V4 相对 V3 的改进；在 242 个双方均可行的交集任务上，V4 距离相对 V3 为 **+7.87%**。两规划器的几何表示与目标不同，跨规划器 cost reduction 不适用。

固定任务使用合成实验室世界与注册目标；56 个 V4 可行计划含注册充电点访问，这只是规划访问，不是实测充电。p50/p95 是测试主机上的请求内壁钟，不是现场吞吐。结果既不证明模型能力，也不证明新 Nav2 三臂转移。

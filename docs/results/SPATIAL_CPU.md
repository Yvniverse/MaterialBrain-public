# CPU 空间规划：1,000 项固定任务

<a id="固定种子空间任务规划cpu-结果"></a>

语义路网约束规划在固定种子的 **1,000 项任务**上，返回 **791 个满足约束的计划、192 个正确不可行拒绝、17 个未解任务**。网格路径与停靠顺序优化在其中 **234 组双方可行配对任务**上，相对按输入顺序执行，将总距离降低 **32.21%**、总目标降低 **26.39%**。

## 规划方法与基线

**V3** 使用朝向栅格 A* 计算停点间路径，再优化访问顺序；其基线是按请求输入顺序访问停点，两者使用相同几何表示和目标。**V4** 在版本化语义有向图上计算路径，由 OR-Tools 处理载重、服务时间、优先级、时窗、电池及充电约束。此次 V4 保持原有单 CPU 线程、seed-zero、每请求 2 秒求解上限。[规划架构](../architecture/04-spatial-planning.md) · [WarehouseBench](../../backend/warehouse_bench/README.md)

任务使用固定的合成实验室世界及注册停靠目标，模型后训练与 Nav2 行驶分别评测。

| 指标 | 结果 |
|---|---:|
| V4 独立审计可行计划 | 791/1,000 |
| 预先证明不可行请求的正确拒绝 | 192/192 |
| 未获得可行解且未证明不可行的搜索失败 | 17/1,000 |
| 约束违规／几何碰撞／程序错误 | 0／0／0 |
| V4 请求内规划 p50／p95 | 406.28／621.63 ms |
| 完整 CPU 执行耗时 | 1,452.035 s |
| V3 优化相对输入顺序：同目标可行配对 | 234 组 |
| 上述 V3 配对的总目标变化 | −26.39% |
| 上述 V3 配对的总距离变化 | **−32.21%** |
| V4 相对 V3：242 组双方可行任务的距离变化 | **+7.87%** |

V3／V4 使用不同的几何表示和目标，因此跨规划器比较采用距离；**26.39%** 的目标下降和 **32.21%** 的距离下降均来自 V3 相对输入顺序的配对比较。17 个搜索失败保留为未解任务，没有独立不可行证明。

## 时间与资源度量

p50／p95 是测试主机上的请求内规划壁钟时间。规划中的时间与能耗按路径和机器人参数预测；**56** 个 V4 可行计划包含注册充电点访问，表示规划的充电停靠。

模型评测中的 `mission_cost` 则是 symbolic 任务环境的时间与能量单位加权值。Nav2 的距离和时间由仿真运动遥测累计，其 `energy_wh` 按行驶距离×`wh_per_m` 加运行时间×`idle_w`／3600 估算。硬件电耗需另行测量。[Nav2 度量实现](../../robot_bridge/ros2/materialbrain_ros2/mission_bridge.py)

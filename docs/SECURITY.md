# 安全说明

- 密码使用 Argon2id，不记录明文；至少 6 位，允许仅使用数字；登录失败达到阈值临时锁定；
- 会话令牌仅存 HttpOnly、SameSite=Strict Cookie，数据库只存 SHA-256；写请求使用独立 CSRF Token；
- 权限在后端逐端点声明，401 与 403 分离；管理员和敏感变更写审计；
- Nginx 限制登录速率、上传 20 MB、设置 nosniff/frame/referrer 头；附件使用随机文件名、扩展名白名单和 SHA-256；
- 数据库不发布端口，容器使用内部网络；生产密码只在 `.env`，`.gitignore` 排除；
- 正式环境建议内部 HTTPS、`COOKIE_SECURE=true`、只开放受控办公网段、定期升级基础镜像并进行备份恢复演练；
- 当前实现没有杀毒引擎，来自外部的附件应先由公司端点安全软件扫描；恢复操作仅允许服务器管理员执行。
